# ResolveMate AI 

**The Autonomous AI Teammate that doesn't just reply — it resolves.**

Built for the **Paytm Build for India AI Hackathon** (Track 3: Autonomous AI Teammates).

## 🔗 Live Demo
**[Test the working prototype here!](https://resolvemate-six.vercel.app/)**

## 💡 Problem
Merchant Support is the silent growth killer. Thousands of merchants send panicky Hinglish messages every day, but current bots only give generic replies and cannot take action. High-risk and high-value cases wait while agents do mechanical work.

## 🛠️ Architecture (Zero Fund Rights)
1. **LLM (Sarvam 105B / Gemini)**: Intent Extraction
2. **Context Assembly**: Merchant Ledger & Risk Profile
3. **Deterministic Policy**: RBAC, Limits, AML Flags
4. **Cryptographic Token**: SHA-256 Single-use Authorization
5. **Tool Runtime**: API Execution & Immutable Audit Log

## 💎 USP
**ResolveMate AI = Action + Safety + Transparency + Human Control**
- LLM has **Zero Fund Rights** (cannot execute transactions on its own).
- Rich, ready-to-act escalation briefs for human agents.
- Full cryptographic audit trails for regulatory readiness.
